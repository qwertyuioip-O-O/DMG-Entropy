# 세 집단 15,000판 재검증 — 2026-10-23

현재 채택본 R19 mode3 / g10static을 고정하고 새 자료로 재학습하지 않았다. 이전 답변의 1,317판·89,230반수는 주로 온라인 속기/래피드였으므로 세 집단을 대표하는 결과가 아니었다.

## 무엇을 신뢰할 수 있는가

- 일반: 기재 온라인 레이팅 801–2200, 무타이틀 참가자 3,328명, 33개 출처. 아레나와 미리 정한 참가자 공개 대국 기록을 혼합했다. 모든 수준·시간제어의 인간 모집단을 무작위 추출한 것은 아니다.
- 엘리트: 기재 Elo 2600–2909, 442명, 25개 출처. 국제대회 중계 959판과 세계 정상급 8명의 선수별 공개 PGN 아카이브 4,041판이다. 2차 아카이브는 Git 커밋/파일 해시를 고정했다. 역사적 PGN에는 타이틀/FIDE ID 누락이 있어 모든 신원을 독립 확인했다고 주장하지 않는다.
- 랜덤: 매 반수 전체 합법 수를 균등 추첨했다. 5,000판·1,744,692반수이며 512반수 상한으로 끝난 460판을 포함했다. 특정한 합성 생성 규칙의 평가다.
- 과거에 저장된 기보와의 완전한 UCI 수열 중복 0, 집단 안 중복 0, 세 집단 사이 완전 수열 중복 0이다. 선수·대회·오프닝의 상관까지 제거한 것은 아니다.
- PGN 파싱 오류/비표준 시작/짧거나 미완료인 기보는 기록한 규칙으로 제외했다. 모든 평가 입력은 자체 코덱에서도 합법 수/정확 복원/결정성을 검사했다.
- 120회 native 실행, 60회 국면 계측 호출의 360행을 유지했다. 느린 실행을 제거하지 않았다. native 동일 입력 2회 비교에서 max/min>1.25인 국면 쌍은 일반 1/40, 엘리트 0/40, 랜덤 0/40이었다.
- 95% 구간은 250판 묶음 20개를 10,000회 재추출한 조건부 bootstrap 구간이다. 출처 선택 편향, 선수 상관, 다른 CPU의 차이를 모두 포함한 모집단 보증은 아니다.
- CPU는 AMD EPYC 9V74의 논리 코어 1개에 고정했다. 국면 계측은 게임 초기화·프레이밍·CRC를 제외하며 별도 빌드의 코드 배치/계측 비용 차이가 있다.
- 오프닝은 24반수 미만이면서 기물 phase>=18, 엔드는 phase<=8, 나머지는 미들이다. phase=min(24, 양측 N+B+2R+4Q).
