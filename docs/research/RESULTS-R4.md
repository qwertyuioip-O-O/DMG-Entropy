# DMT4 미들게임 선택 모델 실험 보고서

작성: 2026-10-20. C++20 구현, 실제 파일 압축·복원 측정. 미리 정한 3.89 bpp 목표에 대해 성공/실패를 모두 공개한다.

## 연구 가설과 대조

- 기존 DMT3 프로필 42와 완전히 동일한 `r4-control` 프로필 45를 구성하고 DMT3 bit/CDF 대조군으로 사용했다.
- 문맥 모델 46: 후보 포획 수 0 / 1–2 / 3+ / 체크 중이라는 **복원자가 알 수 있는 정보**로 기존 전술 특징에 별도의 정수 온라인 잔차를 학습했다.
- 상대 순위 47: 후보 사이에 공통으로 존재하는 특징보다 **전술 손익, 저렴한 중앙 접근성 등의 상대적 순위**를 계산한 뒤 8개의 이진 특징으로 학습했다. 실제 착수의 index를 보고 순위를 계산하는 것은 금지했다.
- 불확실성 보정 48: 동일 문맥에서 **이미 복원한** 실제 수의 낮은 예측 확률 빈도에 따라 uniform guard 강도를 조절했다.
- 49–53: 모델 결합·학습률/guard 대조.

순위 feature의 순위는 포획 여부·같은 이동 기물 종류로 정해지는 그룹과 전체 후보 집합 양쪽에서 측정한다. 이는 엔진의 최적수 순위를 뜻하지 않는다. 앞서 제안한 실제 SEE는 DMT2/3의 10개 전술 특징에 이미 포함되어 있고 새 모델이 재사용한다.

## 결과: 기존 개발용 23게임 (1,718반수)

| 프로필 | 전체 payload bpp | 미들게임 CDF bpp | 전체 파일 bytes |
|---|---:|---:|---:|
| DMT3-42 / DMT4-control | 3.8690 | 3.9235 | 868 |
| DMT4 문맥 전용 46 | 3.8469 | 3.8813 | 864 |
| DMT4 상대 순위 47 | 3.8388 | 3.8651 | 862 |
| DMT4 guard 48 | 3.8685 | 3.9221 | 868 |
| **DMT4 문맥+상대 순위 49** | **3.8289** | **3.8465** | **860** |
| DMT4 세 요소 모두 52 | 3.8271 | 3.8430 | 859 |

국면별 프로필49: **오프닝 3.8618, 미들게임 3.8465, 엔드게임 3.7032 CDF bpp**. 이 표본에서 세 구간이 3.89 이하인 것은 사실이지만 표본은 수차례 연구에 사용된 개발 데이터다. **전체 파일은 860×8/1718 ≈ 4.0047 bpp**로 총 저장 비용 3.89 목표는 미달이다.

## 결과: 2024 세계선수권 1–13국 (1,155반수, 미들게임 579반수)

| 프로필 | 전체 payload bpp | 미들게임 CDF bpp | 전체 파일 bytes |
|---|---:|---:|---:|
| DMT3-42 / DMT4-control | 4.1126 | 4.3901 | 622 |
| DMT4 문맥 46 | 4.0883 | 4.3426 | 619 |
| DMT4 상대 순위 47 | 4.0589 | 4.2831 | 614 |
| DMT4 guard 48 | 4.1108 | 4.3882 | 622 |
| **DMT4 문맥+상대 순위 49** | **4.0485** | **4.2616** | **613** |
| DMT4 세 요소 모두 52 | 4.0485 | 4.2618 | 613 |

프로필49는 DMT3 대비 총 **74 payload 비트 절감**(4,750→4,676비트). 중반 평균 로그 손실 약 **0.1285bit/반수 개선**. 국면별 나머지는 오프닝 3.9465, 엔드게임 3.7055로 DMT3과 같음.

**매우 중요한 평가 제한:** 이 13게임은 DMT3에서 새로 수집해 그 결과를 보고 미들게임 실패 원인을 연구한 시점부터 **더 이상 새 알고리즘에 대해 독립된 최종 검증 데이터가 아니다**. 이 보고서는 이 자료에서 관측한 효과를 개발·분석용 수치로만 제시한다. 인간 전체 및 다양한 Elo·시간제어에서의 범용성 입증은 미완료다.

## DMT3 저확률 착수 진단 — 같은 세계선수권 13게임

DMT3 vs DMT4-49의 **실제 착수마다** CDF 로그 손실을 비교하여 579개 미들게임 착수를 분해했다. 전체 절감량은 약 **74.40 이상 로그손실 비트**.

| 구간 | 착수 수 | DMT3 bpp | DMT4-49 bpp | 절감 로그손실 비트 |
|---|---:|---:|---:|---:|
| 포획수 | 143 | 2.8025 | 2.4880 | 44.97 |
| 비포획수 | 436 | 4.9108 | 4.8433 | 29.43 |
| 3개 이상 포획 후보가 존재 | 302 | 4.4123 | 4.2418 | 51.49 |
| 1–2개 포획 후보 존재 | 240 | 4.5870 | 4.4948 | 22.11 |
| 체크를 받고 있는 국면 | 22 | 1.6038 | 1.6213 | **-0.38 (악화)** |

- DMT3에서 rank 9위 이하인 실제 착수: **253개 / 579개**. 해당 선택들의 평균 로그손실은 약 **5.913bit**였고 DMT4는 **5.820bit**로 완화했다.
- 확률이 1/64보다 작았던 착수 수는 DMT3 98개, DMT4 101개였다. **합계 비트 수가 줄어도 꼬리 사건의 개수는 증가할 수 있다.**
- 특히 전술/포획의 개선이 전체의 많은 부분을 차지했다. 비포획수 436개의 손실이 여전히 약 4.843bit/반수로 높아 다음 연구의 병목이다.
- 각 게임·ply·UCI·후보수·선택 순위·소속 문맥·실제 CDF 확률·로그손실은 CSV에 모두 기록했다. 어떤 수에 대한 **실제 코드 결과**인지 확인 가능하다.

## 처리 속도

현 환경의 Release 단일 스레드 반복 7회, 실행마다 8회 cold start, 중앙값. 컴파일 옵션 `-O3` 및 플랫폼 기본 명령어(no -march=native). PGN 파싱 및 I/O 제외.

| 자료 | DMT4-49 encode | decode |
|---|---:|---:|
| 개발용 23게임 | 약 **71.1K 반수/s** | **70.5K/s** |
| 선수권 13게임 | 약 **68.8K/s** | **67.5K/s** |
| 무작위 48게임 | 약 **58.1K/s** | **60.1K/s** |

사람 대국 표본에서는 설정된 60K/s 하한을 통과했지만, 무작위 대국 인코딩은 그보다 느렸다. VM 성능 편차가 있으므로 하한을 모든 환경에서 보장하지 않는다. 상대 순위 계산은 처음에 O(M²)였고 정수 히스토그램으로 바꾼 뒤 **같은 13게임의 전체 선택 확률/trace가 바이트 동일**한 것을 비교했다.

## 정확성 및 재현

- 기존 DMT1·DMT2·DMT3 모든 포맷의 골든 파일과 동일 출력/복원 규칙 유지.
- 신규 DMT4 전용 magic와 profile 45–53; 예전 모델 ID가 새 버전으로 위장하면 거부.
- DMT4-control 프로필45는 DMT3-42와 파일 헤더·CRC 외 모두 동일하며, 중반 CDF 확률 trace도 정확히 일치한다.
- `ctest` **7/7 PASS**, `dmg_mid_tests` **54개 프로필 전체 왕복·재인코딩 결정론·CRC 손상 거부 PASS**.
- 새 DMT4 프로필49의 `human23` 골든 파일 추가.
- `-fsanitize=address,undefined` 빌드에서 `dmg_mid_tests` 전체 **PASS**.
- 2024 WCC13 추가 데이터는 지난 검증 패키지의 `data/wcc2024_independent13.uci-bundle`과 일치하는 번들. 기존 14국은 개발게임에 포함되므로 이번에도 제외.

## 결론

**실제 실험은 성공적이지만 범용 목표 달성은 실패.** 상대적 개선은 개발용 23게임·4게임·기존 WCC13에서 모두 보였고 human 23게임에서는 미들게임 3.8465를 기록했다. 그러나 이미 실패를 분석한 WCC13 미들게임은 4.2616으로 목표를 크게 초과했으며, 비포획수·조용한 미들게임 예측이 핵심 잔여 문제다. 새 기력/시간제어 분포의 인간 대국 수천 게임을 완전히 별도의 세트로 확보해 profile49를 동결 후 한 번 평가하기 전에는 `범용 3.89` 달성으로 선언할 수 없다.
