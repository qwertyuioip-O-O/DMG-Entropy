# DMG-Entropy 미들게임 확률 개선 — 17개 프로필 실측 보고서

작성일: 2026-10-20. C++20, 기존 DMG8-Fast / Phase-R1 코드에서 분기한 실험 프로젝트 **DMT1**. 실제 압축·복원 테스트 결과이며 **사전학습 모델 없음**.

## 결과 요약

**DMG8-Fast 유지가 현재의 정식 권고**이다. 가장 작은 실험 압축 스트림은 `all-tactics-guard`로 기존 23게임 / 1,718반수에서 **payload 6,857 → 6,768 bit**, 실제 파일 **895 → 883 byte**. 미들게임 893반수의 이상적(실제 양자화 CDF) 로그 손실은 **4.069059 → 3.969415 bit/반수**이다. 4개의 이미 개발에 사용한 다른 인간 게임에서 역시 미들게임 **4.343015 → 4.282908 bit/반수**로 개선됐다. 그러나 서로 다른 독립적 인간 대국에서 성공을 검증하지 않았으며 국면별 3.89bit 목표 달성에도 실패했다.

개발 샘플 중 **오프닝 4.007606, 엔드게임 3.703177**은 이 실험에서 변경하지 않았다. 코덱은 오직 미들게임만 교정하므로 전체 평균 개선값이 미들게임 개선값보다 작다.

**속도 주의:** all-tactics-guard는 복잡한 후보별 평가 때문에 이번 공유 VM의 연속 5회 시도 중앙값 기준 인코딩 약 **66K반수/s**. 같은 실험 빌드의 baseline은 약 **86K반수/s**였다. 다른 날의 97K/s와 정확히 직접 비교할 수 없다. 사용자가 충분하다고 정한 97K/s보다 느리며, 목표 충족을 주장하지 않는다.

## 테스트한 전 방법 / 미들게임

동일한 원시 착수 순서·동일한 헤더 규칙·원본 DMG8의 온라인 학습을 유지하면서 다른 DMT1 모델만 비교했다. `stage_bpp`는 실제 전송 비트의 국면 분리가 아닌 `-log2(CDFfreq/total)` 합계다. `payload_bpp`는 실제 산술 부호화 비트스트림이다. 모든 압축은 각각 cold start였다.

### 실험군 설명

- **확률 교정:** `flat-mild`(정수 근사 q^0.75), `flat-strong`(q^0.5), `sharp`(q^1.25), `guard5/12`(기존 q의 5%/12%를 균등 질량에 할당), `temp-mixture`(원본과 mild 간 온라인 Bayes + fixed-share), `temp-conditional`(후보수·top probability 기반 mild 선택).
- **SEE:** `see`는 포획 수에 한하여 최대 8회 합법 재포획을 최저 가치 공격자 기준으로 추적하고 교환 이득/손해를 2개 특징으로 분류한다. *깊이 8 제한·탐욕적 공격자 선택이므로 완전한 SEE나 체스 엔진 탐색이라고 주장하지 않는다.*
- **새 위협:** `new-threat`는 이번에 움직인 기물이 이전에는 공격받지 않던 상대의 고가치 기물을 새로 공격하는지를 계산하며, 복수 새 위협을 별도 특징으로 구분한다.
- **자기 이전 수 이력:** `own-history`는 같은 기물의 연속 이동 및 이전 자기 착수 도착 파일과 현재 목적지 파일의 일치를 특징으로 사용한다.
- **강제 대응:** `forced-response`는 직전 상대의 도착 기물이 공격 중인 자기 기물을 회피하는지, 그 기물을 새로 위협하는지를 사용한다. 진정한 minimax 강제응수 판정이 아닌 저비용 프록시다.
- **온라인 학습:** 모든 신규 전술 특징은 실제 후보집합의 기대 활성 질량과 선택 수의 차이로 정수 온라인 잔차학습한다. `adaptive-residual`은 노출 수에 따라 개별 특징의 학습률을 변경한다. `all-tactics`는 위 4가지 전술군을 결합, `all-tactics-guard`는 5% guard도 적용한다.
- **근사 SEE:** `see-proxy`는 첫 응수 시 단순 물질 손실을 쓰며, `all-fast`는 이를 다른 모든 새 특징과 결합한다. 정확한 교환 연쇄 대신 1차 재포획 위험만 판단하기 때문에 빠르지만 분별력이 낮을 수 있다.

### 원인 분석

균등 guard만 적용해도 미들게임 로그 손실을 줄였지만, 온도를 강하게 평탄화하면 저확률 착수의 손실이 감소해도 다른 착수에서의 손해가 더 커졌다. **반수당 전체 로그 손실이 기준**이므로 long-tail 건수 감소만으로 개선을 주장하지 않는다. 반면 교환, 위험 대응, 새 위협의 작은 조건부 잔차는 정보가 서로 다르기 때문에 조합 이익이 존재했다. 재포획 값이 꼭 참 최선수를 맞힌다는 가정은 사용하지 않았다.

### 무작위 합법 착수 진단

무작위 16게임 1,024반수(고정 시드)에서는 `baseline` 전체 payload **5.1426 bpp**, `all-tactics-guard` **5.1074 bpp**였다. `flat-strong`은 **4.9932 bpp**로 더 낫지만, 이는 인간 기보 예측의 우수성을 뜻하지 않는다. 무작위 합법수 생성 분포의 기대 엔트로피를 뛰어넘는다는 주장도 아니다.

같은 4게임을 3회 반복하는 시험에서는 baseline payload **3.7802**, all-tactics-guard **3.7419 bpp**였으나 반복된 게임에 대한 값은 정상적 일반 대국 평가에 사용할 수 없다.

## 새 특징들이 실제로 활성화됐는가?

기존 23게임의 미들게임에서 실제 선택 수 893회 중, 아래 특징들이 선택 수에서 활성화된 횟수를 기록했다. 상대 후보에서는 그보다 많이 발생하고, 학습이 다른 후보들과 비교된다.

| 특징 | 선택 수 활성화 | 전체 경쟁 후보 활성화 |
|---|---:|---:|
| 교환 이득 ≥1폰 | 169 | 502 |
| 교환 손해 ≤-1폰 | 16 | 1329 |
| 기존에 없던 고가치 위협 | 226 | 6143 |
| 새 고가치 위협 2개 이상 | 24 | 883 |
| 직전 자기 기물 재이동 | 207 | 4632 |
| 이전 자기 수와 목적지 파일 동일 | 112 | 2697 |
| 직전 상대가 위협한 기물을 이동 | 256 | 2728 |
| 직전 상대 기물을 새로 위협 | 121 | 2756 |

**구현상 주의:** `Position::apply_unchecked()`는 side-to-move를 변경한다. 새 위협과 직전 상대 수의 공격을 계산할 때 `pseudo_destinations()`가 읽는 side를 명시적으로 맞춰야 한다. 처음에 이 부분을 잘못 처리한 시제품은 특징이 전부 비활성이었고, **오류를 수정한 뒤 모든 실험을 다시 실행**했다. 보고된 값은 수정 완료 후 측정이다.

## 정확성 검증과 재현

- CTest 기존 6개 + 신규 1개 = **7/7 통과**.
- 신규 DMT1 17 프로필에서 빈 아카이브·23개 사람 기보·무작위 8게임의 무손실 왕복, 바이트 동일 재압축, CRC32 손상 거부.
- 기존 DMG6/7/8/9/DMP1 디코더 경로는 수정하지 않았다. frozen DMG8 payload는 신규 baseline과 **6,857 bit 동일**.
- `examples/golden/human23-mid-all.dmt` = 883B, SHA-256 `ab0d07509453a1cc7a175777410365ed0120393d41216ca19fb4be396a643128`. golden stream 재인코딩/디코딩 확인.
- `-fsanitize=address,undefined`, `-O1 -g`로 빌드한 신규 17 프로필 테스트 통과(`ASAN_OPTIONS=detect_leaks=0`). Rust/ARM/WASM 교차 검증은 아직 수행하지 않음.
- CDF 후보마다 0이 아닌 정수 질량을 유지하고, 새 전술 특징·posterior는 **그 수가 복원된 후** 갱신한다. 신규 DMT1은 DMG8 바이너리와 다른 magic/profile을 사용하므로 기존 파일 의미를 변경하지 않는다.
- 속도 수치는 **공유 VM**에서 파일 로딩을 제외한 한 차례 encode/decode 벤치마크를 5회 반복한 중앙값. 코덱 실행에 DMT1 헤더와 CRC 비용은 포함되며 각 mode마다 동일한 데이터 사용. VM 부하로 편차가 있어 정밀 속도 순위를 주장하지 않는다.
- 개발 표본에서 17개 모델을 비교해 유리한 모델을 선정했으므로 **선정 편향**이 있다. 이 표본의 개선을 추정된 일반화 효과라고 해석하지 않는다.

```sh
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j4
ctest --test-dir build --output-on-failure
./build/dmg_mid_bench examples/heldout/*.uci > results-mid/retest.csv
./build/dmg_mid pack all-tactics-guard archive.dmt examples/heldout/*.uci
./build/dmg_mid unpack archive.dmt restored_games/
```

## 다음 결론

1. **성공한 것:** 새 위협/교환/자기수/강제대응이라는 미들게임 신호와 확률 보호를 각각 실 코덱으로 시험했다. 23게임과 다른 4게임에서 방향이 일치하는 **개발용 개선**을 확인.
2. **달성 못한 것:** 3개 국면 모두 ≤3.89 bit/반수, 독립 인간 기보의 안정적 개선, 97K수/s 속도 유지. 테스트 23게임에서 미들 3.9694이므로 여전히 **약 0.0794 bit/반수** 추가 감축이 필요.
3. **메인 승격 불가:** 교환 평가와 위협 재계산이 득은 내지만 속도를 떨어뜨린다. 따라서 **DMG8-Fast는 메인**, `DMT1 all-tactics-guard`는 개선 가능성이 있는 연구 브랜치로 유지하고, 우선 빠른 조건부 위험·위협 계산/특징 검증에 집중.
4. **범용성 검증:** 새로 확보한 현대 저·중·고기력 인간 기보를 시간제어별로 분리한 **수천 게임 이상의 독립 자료**에서 동일 조건 비교한 후 승격 결정. 현재 데이터셋 자체는 이 결론을 내릴 만큼 넓지 않다.
